# Native OS access

Owns read-only Linux, macOS and Windows collection and platform handles behind safe Rust APIs. The application schedules sampling; this module does not create a second sampler.

See the [product guide](../../README.md), [protocol](../../docs/protocol.md) and
[quality contract](../../docs/quality.md). Root `just check` reads source;
native behavior and packaging are qualified on build hosts and CI.
